3.3 结论

NAND 寿命影响 ≈ 零;读带宽才是真约束。①SSD 磨损只由写入造成,Engram 路径是纯读,累计写入仅 59GB(寿命的 0.02%),日常写只有日志 KB 级;即使每天 100 次满负荷 512K prefill(读 1.6TB/天),对 NAND 也零损耗——读不磨盘,温度实测 40°C 健康。②真正的约束是读带宽:合成词全 miss 场景每 prefill token 要 31-40KB 盘读,SATA 随机读 ~54MB/s 有效吞吐把并发 prefill 钉在 ~1,000 tok/s(0731 的 1/4.7);前缀缓存命中时盘读归零(实测 0.1MB),真实自然语言的 n-gram 局部性会显著优于合成词,但重复率低的冷文档仍会吃满盘带宽。③缓解已就位:热区预载脚本(engram-prewarm.sh)+ 前缀缓存开启中;根治要靠 NVMe(Gen3×4 = 8 倍随机读)——但那违反本项目"零新增硬件"前提,列为后续选项。
